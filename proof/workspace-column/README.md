# Workspace column browser proof

    node build.mjs <phonux checkout> out.js
    PLAYWRIGHT_MODULE=<path to playwright/index.mjs> node run.mjs out.js <chromium|webkit|firefox> <outdir>

Three workspaces in a column at 1280x832 and 1280x1080: cells, inert state, neighbour buttons (24 px minimum), the name input above the headers, ArrowDown, a rename, Create new workspace at the top, no console warnings. Not part of the library gate.
